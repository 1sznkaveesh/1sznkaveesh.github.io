# kaveesh.github.io

Personal academic site of Kaveesh Chaudhari. It is plain static HTML/CSS with no build step, served by GitHub Pages.

```
index.html          Home: bio, research, projects, contact
style.css           Single shared stylesheet (light + automatic dark mode)
projects/*.html     Research write-ups and project pages
assets/img/         Figures and thumbnails
assets/video/       Demo clips
docs/               Provenance notes for figures
```

Preview locally: `python3 -m http.server` and open http://localhost:8000.
