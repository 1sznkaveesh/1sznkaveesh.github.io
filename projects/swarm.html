Project · Multi-agent planning

Robots that sort out traffic among themselves

A grid-world simulator where each robot plans its own route and works out right of way with its neighbours. There is no central controller telling anyone what to do.

In progress Python · A* search Code

This project explores decentralized path planning and coordination for small-scale multi-robot systems. A central controller is a single point of failure and a processing bottleneck, so here each agent runs its own A* search on a shared discrete grid and coordinates only with nearby agents. The aim is multi-robot routing that scales without large spikes in computation.

Components

The simulator exposes three interaction modes for setting up a scenario:

  • Robot nodes Agents that plan and follow paths through the grid in their own local frame, each tracking its position relative to its neighbourhood.
  • Cargo boxes (task allocation) Static task locations. Agents pair themselves with tasks by negotiating with adjacent agents, without a central dispatcher.
  • Target goals Destination points that multiple agents converge on, with crossing priorities updated on the fly to avoid deadlock.

Conflict resolution

The main problem is deadlock at intersections. Instead of broadcasting to the whole network, agents share their planned paths only with nearby agents. When two planned trajectories cross, the agents involved stagger their movements, with one waiting while the other passes. This reduces total waiting time during simultaneous crossings.

Runtime metrics

A live monitor tracks each agent so the planner's behaviour can be measured and tuned:

  • Fitness score A per-agent score based on path efficiency, energy use and whether the agent reached its goal.
  • Moves, waits and turns Counted per agent. Wait counts in particular give direct feedback on how well the local prioritization rules are working.
